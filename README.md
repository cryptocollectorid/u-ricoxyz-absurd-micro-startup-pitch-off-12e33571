## Entry

> We sell a subscription that watches your plants, judges your watering schedule, and sends a weekly report card to your mother-in-law.

(133 characters, one sentence.)

## How it works

`main.py` writes the pitch to `/output/entry.txt` and prints it. It validates the gate first: 1–200 characters, not only white space, exactly one sentence.

Run it:

```sh
python3 main.py
```
